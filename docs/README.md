Создать .py файлы для простейших геометрических фигур с вычислением площадей и периметров

## Документирование
Предоставить документацию по проекту

# Описание каждой функции с примерами вызова 
## Общее 
В каждом .py файле используются формулы из раздела **"Math formulas"** этой документации


## Circle (круг)
### area(r)
Возвращает площадь круга по радиусу 

_Пример: area(5) вернет 78.53981633974483_

### perimeter(r)
Возвращает длину окружности круга по радиусу

_Пример: perimeter(5) вернет 31.41592653589793_


## Rectangle (прямоугольник)
### area(a, b)
Возвращает площадь прямоугольника по двум сторонам

_Пример: area(4, 5) вернет 20_
### perimeter(a, b)
Возвращает периметр прямоугольника по двум сторонам

_Пример: perimeter(4, 5) вернет 18_


## Square (квадрат)
### area(a)
Возвращает площадь квадарата по одной стороне

_Пример: area(5) вернет 25_

### perimeter(a)
Возвращает периметр квадрата по стороне

_Пример: perimeter(5) вернет 20_

## Triangle (треугольник)
### area(a, h)
Возвращает площадь треугольника по стороне и высоте

_Пример: area(3, 4) вернет 6.0_

### perimeter(a, b, c)
Возвращает периметр треугольника по трем сторонам

_Пример: area(3, 4) вернет 12_


# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah/2

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
